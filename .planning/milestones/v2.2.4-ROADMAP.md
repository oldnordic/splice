## Overview

This milestone removes dead code that was left behind from an earlier design phase. The `Ingestor` struct was originally intended for Splice to have its own code graph indexing, but this approach was abandoned in favor of using Magellan for indexing while Splice focuses on span-safe editing.

## Migration Guide

For any code still referencing the removed `Ingestor` struct:

```rust
// OLD (removed in v2.2.4)
use splice::ingest::Ingestor;

// NEW - Option 1: Use MagellanIngestor
use splice::ingest::magellan::MagellanIngestor;
let mut ingestor = MagellanIngestor::new(&db_path)?;
let count = ingestor.index_file(&file_path)?;

// NEW - Option 2: Use extract_symbols directly
use splice::ingest::dispatch::extract_symbols;
let source = std::fs::read(&file_path)?;
let symbols = extract_symbols(&file_path, &source)?;
```
