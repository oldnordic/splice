```bash

  --expand --expand-level 1 \
  -C 3 \
  --relationships \
  --json
```

**Result:** ✅ Working
- Expansion: `expand_to_body_with_docs()` called (Phase 16)

- Relationships: `get_callers`, `get_callees` queried (Phase 12)
- JSON: All fields serialized correctly

### Flow 2: Delete with Dry-run + Diff + Exit Codes

```bash
splice delete --db codegraph.db --symbol "obsolete" \
  -n \
  --unified 5
```

**Result:** ✅ Working
- Dry-run: Preview mode active (Phase 13)
- Diff: `format_unified_diff()` called with 5 lines context
- Exit codes: Returns 1 if changes pending (git diff convention)

### Flow 3: Patch with Relationships + Context + Checksums

```bash
splice patch --file src/example.rs \
  --start 100 --end 200 \
  --replacement "new_code" \
  --relationships \
  -A 2 -B 2
```

**Result:** ✅ Working
- Relationships: Caller/callee queries executed (Phase 12)
- Context: 2 lines before/after extracted (Phase 14)
- Checksums: `checksum_before` computed automatically (Phase 11)

### Flow 4: Search with Glob + Context + Apply

```bash
splice search --pattern "TODO" \
  --glob "src/**/*.rs" \
  -C 2 \
  --replace "FIXME" \
  --apply
```

**Result:** ✅ Working
- Glob: Pattern matching for Rust files (Phase 16)
