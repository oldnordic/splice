**Database Compatibility Concern (from docs/manual.md section 12):**

SQLiteGraph v1.0 has two backends:
1. **SQLite Backend** (`SqliteGraph::open()`) - Original format
2. **Native V2 Backend** (`GraphConfig::native()`) - New format with clustered adjacency

The migration changes from SQLite backend (0.2.11 default) to Native V2 backend (v1.0 with native-v2 feature).

**Potential Issue:**
- Existing databases created with 0.2.11 use SQLite backend format
- Native V2 backend may use a different storage format
- May need migration or may be transparent

**Testing Strategy:**
1. Create a test database with old code (if possible) or verify format compatibility
2. Try to open with new code
3. Test basic operations (insert, query, traverse)

**Magellan Integration:**
- src/graph/magellan_integration.rs wraps Magellan's CodeGraph
- Magellan 0.5.3 may use SQLiteGraph internally
- Need to verify it still works after our dependency upgrade

**Rollback Plan:**
If compatibility issues are found:
1. Document the specific incompatibility
2. Consider updating Magellan to a version that uses SQLiteGraph v1.0
3. Or create a migration utility
</context>
