**From Plan 02-01 Discovery:**

Current (0.2.11):
```toml
[dependencies]
sqlitegraph = { version = "0.2.11", default-features = false }
```

Target (1.0 with Native V2):
```toml
[dependencies]
sqlitegraph = { version = "1.0", default-features = false, features = ["native-v2"] }
```

**Why Native V2:**
- Roadmap specifies "Native V2 backend"
- Better performance for graph traversals
- Clustered adjacency for locality
- The current code uses `open_graph()` which is the Native V2 API

**Feature Flag Details (from docs/API.md):**
- `native-v2`: Enables Native V2 backend
- Default: `sqlitegraph = "1.0"` uses SQLite backend only
- We keep `default-features = false` to minimize dependencies

**Related Dependencies:**
- Magellan 0.5.3 also uses SQLiteGraph internally
- Need to verify compatibility after upgrade
</context>
