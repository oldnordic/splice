# Phase 29-01: Rename Command with Symbol Lookup

**Objective:** Add `splice rename` CLI command with symbol lookup supporting ID-first with name+path fallback

**Requirements:** CLI-05 (partial - command structure, --symbol, --to, --db, --preview flags)

## Success Criteria
- User can invoke `splice rename --symbol <id> --to <new_name>`
- User can invoke `splice rename --name <name> --file <path> --to <new_name>` (fallback)
- Symbol lookup resolves both 32-char V2 and 16-char V1 IDs
- Ambiguous symbols produce error listing all matches
- Pre-flight validation: symbol must exist and have references

/// Rename a symbol across all files using byte-accurate references
#[command(display_order = 108)]
Rename {
    /// Symbol ID (32-char BLAKE3 or 16-char SHA-256)
    #[arg(short, long, conflicts_with = "name")]
    symbol: Option<String>,

    /// Symbol name (requires --file)
    #[arg(short, long, conflicts_with = "symbol")]
    name: Option<String>,

    /// File path for symbol name resolution (required with --name)
    #[arg(short, long)]
    file: Option<std::path::PathBuf>,

    /// New name for the symbol
    #[arg(short, long)]
    to: String,

    /// Path to Magellan database (default: .codemcp/codegraph.db)
    #[arg(short, long, default_value = ".codemcp/codegraph.db")]
    db: std::path::PathBuf,

    /// Preview changes without applying
    #[arg(short = 'n', long = "dry-run")]
    preview: bool,

    /// Override backup directory (default: .splice/backups/)
    #[arg(long)]
    backup_dir: Option<std::path::PathBuf>,

    /// Skip backup creation
    #[arg(long)]
    no_backup: bool,
    /// Create backup before rename (default: true for safety, use --no-backup to skip)
    #[arg(long, default_value = "true")]
    create_backup: bool,
},

### Task 3: Add symbol reference query to MagellanIntegration

**File:** `src/graph/magellan_integration.rs`

Add method to `MagellanIntegration`:

```rust
/// Get all references for a symbol by entity ID.
///
/// Returns ReferenceFact entries for all references to this symbol
/// across all indexed files. This is the core data for cross-file rename.
///
/// # Arguments
/// * `entity_id` - Entity ID of the symbol definition
///
/// # Returns
/// Vector of ReferenceFact entries with byte spans
pub fn get_all_references(&self, entity_id: i64) -> Result<Vec<magellan::references::ReferenceFact>> {
    self.inner
        .all_references_for_symbol(entity_id)
        .map_err(|e| SpliceError::Other(format!("Failed to get references for entity {}: {}", entity_id, e)))
}
```
