# Plan 07-03: Implement Post-Verification Hooks

**Phase:** 7 - Validation Hooks
**Status:** PENDING
**Dependencies:** 07-01 (checksums), 07-02 (pre-verification)
**Estimated Complexity:** Medium

## Objective

Implement post-verification hooks that validate the correctness of refactoring operations after modifications are applied. Post-verification ensures that changes produced valid code, maintained expected behavior, and can be safely committed.

## Context

**Current State:**
- `apply_patch_with_validation()` already runs:
  - Tree-sitter reparse gate (`validate_tree_sitter_parse()`)
  - Compiler validation gate (`validate_with_cargo()` for Rust)
  - rust-analyzer gate (`gate_rust_analyzer()` for Rust)
- Rollback on validation failure is implemented
- `before_hash` and `after_hash` are computed but not fully utilized

**Gap Analysis:**
1. No verification that semantic meaning was preserved (only syntax checked)
2. No verification that all references were updated correctly
3. No post-patch checksum comparison (what actually changed?)
4. No verification that file still compiles with full project (only isolated checks)
5. No detection of unintended side effects (e.g., changed import order)
6. No "dry run" verification showing what would change

## Research Required

**Post-Validation Patterns:**
- Database transactions: verify invariants before COMMIT
- Refactoring tools: semantic preservation checks
- Testing frameworks: regression tests after refactor
- Compilers: link-time verification after optimization

**Semantic Preservation:**
- Type signatures unchanged (except intended)
- Public API unchanged (except intended)
- Function behavior preserved (via AST analysis)
- Import structure preserved (unless explicitly changed)

**Validation Layers:**
1. **Syntactic:** Tree-sitter can parse (already implemented)
2. **Compiler:** Native compiler accepts (already implemented for Rust)
3. **Semantic:** Type checking, reference resolution (partial - need expansion)
4. **Behavioral:** Test suite passes (out of scope - user responsibility)

```rust
//! Post-verification hooks for validating refactoring results.
//!
//! Post-verification runs AFTER file modifications to:
//! - Validate syntax (tree-sitter reparse)
//! - Validate compilation (language-specific compilers)
//! - Verify semantic preservation
//! - Check for unintended side effects
//! - Compare checksums to document actual changes

use crate::checksum::{Checksum, checksum_file, checksum_span};
use crate::error::{Result, SpliceError};
use std::path::Path;

/// Post-verification result.
#[derive(Debug, Clone, PartialEq)]
pub struct PostVerificationResult {
    /// Syntax validation passed
    pub syntax_ok: bool,

    /// Compiler validation passed
    pub compiler_ok: bool,

    /// Semantic validation passed
    pub semantic_ok: bool,

    /// Checksums before and after
    pub before_checksum: String,
    pub after_checksum: String,

    /// Warnings (non-blocking issues)
    pub warnings: Vec<String>,

    /// Errors (blocking issues)
    pub errors: Vec<String>,
}

/// Verify file after patching.
///
/// Runs:
/// - Tree-sitter reparse (syntax check)
/// - Compiler validation (language-specific)
/// - Checksum verification (confirm expected changes)
/// - Semantic checks (reference integrity, type preservation)
pub fn verify_after_patch(
    file_path: &Path,
    workspace_root: &Path,
    language: SymbolLanguage,
    expected_before: &str,
    expected_span_checksum: Option<&str>,
) -> Result<PostVerificationResult>;

/// Verify semantic preservation.
///
/// Checks:
/// - Symbol still exists (if not deleted)
/// - Symbol type/kind unchanged (if not intended change)
/// - References still resolve correctly
pub fn verify_semantic_preservation(
    file_path: &Path,
    symbol_name: &str,
    workspace_root: &Path,
    language: SymbolLanguage,
) -> Result<bool>;

/// Verify no unintended modifications outside target span.
///
/// Checks:
/// - Only expected bytes changed (via checksum of non-target regions)
/// - Wh/formatting unchanged outside target
pub fn verify_localized_change(
    file_path: &Path,
    original_content: &[u8],
    target_span: (usize, usize),
) -> Result<bool>;

/// Compare checksums to document what changed.
pub fn checksum_diff(
    before_checksum: &str,
    after_checksum: &str,
) -> ChecksumDiff;

#[derive(Debug, Clone, PartialEq)]
pub struct ChecksumDiff {
    /// Checksums are different (change occurred)
    pub changed: bool,
    /// Estimated size of change (bytes)
    pub estimated_delta: i64,
}
```

```rust
    match run_validation_gates(file_path, workspace_dir, language, analyzer_mode) {
        Ok(_) => {}
        Err(e) => {
            // ... rollback logic ...
        }
    }

    // Step 9: Compute after hash and run post-verification
    let refreshed_bytes = std::fs::read(file_path)?;
    let after_hash = compute_hash(&refreshed_bytes);

    // NEW: Post-verification to confirm expected changes

        file_path,
        workspace_dir,
        language,
        &before_hash,
        Some(&span_checksum_before.value),
    )?;

    // NEW: Check for unexpected post-verification failures
    if !post_verify.semantic_ok {
        log::warn!("Semantic verification failed: {:?}", post_verify.errors);
        // Still succeed if syntax and compiler passed (semantic is advisory)
    }

    // Log warnings for user visibility
    for warning in &post_verify.warnings {
        log::warn!("Post-verification warning: {}", warning);
    }

    Ok((before_hash, after_hash))
}
```

### Step 4: Add Localized Change Verification

**File:** `src/verify.rs`

```rust
/// Verify that changes were localized to the target span.
///
/// Reads current file, masks out the target span region, and verifies
/// that non-target regions match the original content.
pub fn verify_localized_change(
    file_path: &Path,
    original_content: &[u8],
    target_span: (usize, usize),
) -> Result<bool> {
    let current = std::fs::read(file_path)?;

    // Create mask: 0 = target region (ignore), 1 = check region
    let mut matches = true;

    // Check bytes before target span
    if target_span.0 > 0 && target_span.0 <= original_content.len() {
        let before_original = &original_content[..target_span.0];
        let before_current = current.get(..target_span.0);

        if before_current != Some(before_original) {
            log::warn!("File modified before target span");
            matches = false;
        }
    }

    // Check bytes after target span
    let after_start = target_span.1.min(original_content.len());
    if after_start < original_content.len() {
        let after_original = &original_content[after_start..];
        let after_current = current.get(after_start..);

        if after_current != Some(after_original) {
            log::warn!("File modified after target span");
            matches = false;
        }
    }

    Ok(matches)
}
```
