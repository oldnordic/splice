# Overview

**Goal:** Add query capabilities for execution audit trail with a new `splice log` CLI command.

**Context from 08-01/02:** Database is populated with execution records. This plan adds ways to query and display them.

**Key Features:**
1. Query functions with flexible filtering
2. New `splice log` command for CLI access
3. Support for human-readable (table) and machine-readable (JSON) output
4. Date range, status, and operation type filters

```rust
pub struct LogCommand {
    /// Filter by operation type (patch, delete, batch, plan, apply-files, query)
    #[arg(short, long)]
    pub operation_type: Option<String>,

    /// Filter by status (ok, error, partial)
    #[arg(short, long)]

    /// Show operations after this date (ISO 8601 or Unix timestamp)
    #[arg(long)]
    pub after: Option<String>,

    /// Show operations before this date (ISO 8601 or Unix timestamp)
    #[arg(long)]
    pub before: Option<String>,

    /// Maximum number of results
    #[arg(short, long, default_value = "20")]
    pub limit: usize,

    /// Skip first N results
    #[arg(long, default_value = "0")]
    pub offset: usize,

    /// Get specific execution by ID
    #[arg(short, long)]
    pub execution_id: Option<String>,

    /// Output as JSON
    #[arg(short, long)]
    pub json: bool,

    /// Show statistics only
    #[arg(long)]
    pub stats: bool,
}
```

```rust
fn execute_log(
    operation_type: Option<String>,
    status: Option<String>,
    after: Option<String>,
    before: Option<String>,
    limit: usize,
    offset: usize,
    execution_id: Option<String>,
    json: bool,
    stats: bool,
    json_output: bool,
) -> Result<CliSuccessPayload> {
    use splice::execution::query::*;
    use splice::execution::log::init_db;

    let conn = init_db()?;

    // Handle --execution-id
    if let Some(id) = execution_id {
        let log = get_execution(&conn, &id)?
            .ok_or_else(|| SpliceError::ExecutionNotFound { execution_id: id })?;
        return if json || json_output {
            // Output JSON
        } else {
            // Output table
        };
    }

    // Handle --stats
    if stats {
        let stats = get_execution_stats(&conn)?;
        return if json || json_output {
            // Output JSON
        } else {
            // Output formatted stats
        };
    }

    // Build query from filters
    let mut query = ExecutionQuery::new()
        .with_limit(limit)
        .with_offset(offset);

    if let Some(op_type) = operation_type {
        query = query.with_operation_type(op_type);
    }
    if let Some(s) = status {
        query = query.with_status(s);
    }
    // ... date parsing for after/before

    let logs = query.execute(&conn)?;

    if json || json_output {
        // Output JSON
    } else {
        // Output table
    }
}
```

**Date Parsing:**
```rust
fn parse_date(input: &str) -> Result<i64> {
    // Try Unix timestamp first
    if let Ok(ts) = input.parse::<i64>() {
        return Ok(ts);
    }
    // Try ISO 8601
    chrono::DateTime::parse_from_rfc3339(input)
        .map(|dt| dt.timestamp())
        .map_err(|_| SpliceError::InvalidDateFormat { input: input.to_string() })
}
```

## Notes

- Query is read-only, doesn't modify execution log
- Append-only design: no UPDATE/DELETE operations
- Pagination via limit/offset for large logs
- Date parsing supports both Unix timestamp and ISO 8601
- Table output uses comfy-table for nice formatting (consider adding if needed, or use simple tab-separated)
