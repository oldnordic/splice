# Overview

**Goal:** Design and implement execution log schema and recording infrastructure for persistent audit trails.

**Context from Phase 4:** `execution_id` (UUID v4) is already generated for each operation via `OperationResult::with_id()`. `timestamp` is already captured in `OperationResult` using `chrono::Utc::now().to_rfc3339()`.

**Key Question:** Should execution log be in the same SQLite database as codegraph (`codegraph.db`) or a separate database (`operations.db`)?

**Decision:** Separate `operations.db` database. Reasons:
1. Separation of concerns (code graph vs operation history)
2. Easier to clear/backup audit trail without affecting code graph
3. Different growth patterns (code graph is stable, log grows with usage)
4. Can be queried independently

## Tasks

### Task 1: Design execution log database schema

Create `src/execution.rs` module with database schema and table creation.

**Schema Design:**

```sql
CREATE TABLE IF NOT EXISTS execution_log (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    execution_id TEXT NOT NULL UNIQUE,        -- UUID from OperationResult
    operation_type TEXT NOT NULL,              -- "patch", "delete", "batch", "plan"
    status TEXT NOT NULL,                      -- "ok", "error", "partial"
    timestamp TEXT NOT NULL,                   -- ISO 8601 from OperationResult
    workspace TEXT,                            -- workspace root if available
    command_line TEXT,                         -- full command line for reproducibility
    parameters TEXT,                           -- JSON: operation-specific parameters
    result_summary TEXT,                       -- JSON: summary of results
    error_details TEXT,                        -- JSON: error details if status != "ok"
    duration_ms INTEGER,                       -- operation duration in milliseconds
    created_at INTEGER NOT NULL                -- Unix timestamp for sorting
);

CREATE INDEX IF NOT EXISTS idx_execution_log_execution_id ON execution_log(execution_id);
CREATE INDEX IF NOT EXISTS idx_execution_log_operation_type ON execution_log(operation_type);
CREATE INDEX IF NOT EXISTS idx_execution_log_timestamp ON execution_log(created_at);
CREATE INDEX IF NOT EXISTS idx_execution_log_status ON execution_log(status);
```
