<task type="auto">
  <name>Task 1: Create src/diff/mod.rs with unified diff module</name>
  <files>src/diff/mod.rs</files>
  <action>
    Create a new module at src/diff/mod.rs with the following structure:

    **Module documentation:**
    - Module-level docs explaining unified diff generation, color conventions

    **Function 1: should_use_color() -> bool**
    - Checks NO_COLOR environment variable first (accessibility standard)
    - Falls back to TTY detection via std::io::stdout().is_terminal()
    - Returns true if colors should be used, false otherwise
    - Pattern: match std::env::var("NO_COLOR") { Ok(_) => false, Err(_) => std::io::stdout().is_terminal() }

    **Function 2: format_unified_diff(old: &str, new: &str, path: &str, context_lines: usize) -> String**
    - Uses similar::TextDiff::from_lines(old, new)
    - Calls .unified_diff().context_radius(context_lines).header(&format!("a/{}", path), &format!("b/{}", path))
    - Returns String with standard unified diff format
    - Context lines parameter defaults to 3 (git convention)
    - Handles the case where old == new (returns empty string or "No changes" message)

    **Function 3: format_colored_diff(old: &str, new: &str, use_color: bool) -> String**
    - Uses similar::TextDiff::from_lines(old, new)
    - Iterates over diff.iter_all_changes()
    - Applies nu_ansi_term::Color::Red.paint("-") for ChangeTag::Delete when use_color=true
    - Applies nu_ansi_term::Color::Green.paint("+") for ChangeTag::Insert when use_color=true
    - Uses " " prefix for ChangeTag::Equal (context lines)
    - Returns formatted String with ANSI codes when use_color=true, plain text when false

    **Re-exports for convenience:**
    - Export ChangeTag from similar crate for potential external use

    **Tests:**
    - Add basic unit tests for should_use_color() mocking NO_COLOR
    - Add test for format_unified_diff() with known inputs
    - Add test for format_colored_diff() verifying color application

    **Do NOT:**
    - Do NOT add JSON output formatting (handled by output module)
    - Do NOT add file I/O (let callers handle file reading)
    - Do NOT use deprecated atty or ansi_term crates
  </action>
  <verify>cargo check --lib</verify>
  <done>diff module compiles, exports three public functions, includes tests</done>
</task>
