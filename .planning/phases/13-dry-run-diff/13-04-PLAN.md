<objective>
Integrate unified diff output with summary header into patch and delete commands when dry-run is enabled.

Purpose: When users run `splice patch --dry-run` or `splice delete --dry-run`, they should see a git-style summary header followed by standard unified diff output showing exactly what would change. The summary header displays file count, insertions, and deletions (e.g., " 1 file changed, 5 insertions(+), 3 deletions(-)"). The diff should use colors (red for deletions, green for additions) when outputting to a terminal, but respect the NO_COLOR environment variable. In JSON mode, colors should always be disabled.

Output: Working dry-run mode for patch and delete commands with summary header and colored unified diff output.
</objective>

  <name>Task 1: Add summary header function to diff module</name>
  <files>src/diff/mod.rs</files>
  <action>
    Add a new function `format_diff_summary()` to src/diff/mod.rs:

    **Function signature:**
    ```rust
    pub fn format_diff_summary(files: usize, insertions: usize, deletions: usize) -> String
    ```

    **Behavior:**
    - Follows git's summary format exactly:
      - 1 file: " 1 file changed"
      - Multiple files: " N files changed"
      - Insertions: " N insertion(+)" or " N insertions(+)"
      - Deletions: " N deletion(-)" or " N deletions(-)"
    - Example outputs:
      - " 1 file changed, 5 insertions(+), 3 deletions(-)"
      - " 2 files changed, 10 insertions(+), 2 deletions(-)"
      - " 1 file changed, 1 insertion(+)"
      - " 1 file changed, 1 deletion(-)"
      - " 1 file changed, 0 insertions(+), 0 deletions(-)" (edge case: no actual change)
    - Use singular/plural correctly (insertion vs insertions, deletion vs deletions)
    - Returns empty string if files == 0 (nothing to summarize)

    **Placement:**
    - Add after the `format_colored_diff()` function
    - Include module documentation explaining the git-style format

    Add a unit test that verifies the output format matches git's conventions.

    Note: The re-export for this function is already added to lib.rs in Plan 13-02.
  </action>
  <verify>cargo check --lib && cargo test --lib format_diff_summary</verify>
  <done>Summary header function produces git-style output with correct pluralization</done>
