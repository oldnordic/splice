Simulate an LLM discovering code structure using only the splice CLI:

1. Create TempDir with multi-file Rust project:
   - src/main.rs: fn main() { helper(); process(); }
   - src/helper.rs: pub fn helper() {}
   - src/process.rs: pub fn process() { helper(); }

3. Discovery workflow sequence:
   a. Run `splice status --db <db_path> --output json`

      - Extract all function names (main, helper, process)
   c. Run `splice find --db <db_path> --name process --output json`
      - Get symbol metadata (file_path, byte range)
   d. Run `splice refs --db <db_path> --name process --direction out --output json`
      - Get callees (process -> helper)
4. Validate each step returns structured JSON with:
   - status == "ok"
   - All required fields present
   - Consistent field naming across commands (start_line, end_line, etc.)
5. Validate no tool switching required - all commands use same binary

This test simulates the LLM pattern: "What functions exist? -> Tell me about X -> What does X call?"
