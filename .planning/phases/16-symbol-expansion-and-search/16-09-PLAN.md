<task type="auto">
  <name>Task 2: Update execute_search to handle glob patterns</name>
  <files>src/main.rs</files>
  <action>
Modify execute_search to:
1. Accept glob: Option<String> parameter
2. When glob is Some, use it directly as glob_pattern
3. When glob is None, build glob pattern from path and language:
   - If language specified: "{path}/**/*.{ext}"
   - If no language: "{path}/**/*.{rs,py,c,cpp,h,hpp,java,js,ts,tsx}"

Implementation:
```rust
let glob_pattern = if let Some(g) = glob {
    g
} else {
    // Build default glob based on language or all supported types
    let extensions = if let Some(lang) = language {
        match lang {
            cli::Language::Rust => "rs",
            cli::Language::Python => "py",
            cli::Language::C => "c",
            cli::Language::Cpp => "cpp",
            cli::Language::Java => "java",
            cli::Language::JavaScript => "js",
            cli::Language::TypeScript => "ts",
        }
    } else {
        "{rs,py,c,cpp,h,hpp,cc,cxx,java,js,mjs,cjs,ts,tsx}"
    };

    if path.is_dir() {
        format!("{}/**/*.{}", path.display(), extensions)
    } else {
        path.display().to_string()
    }
};
```
  </action>
  <verify>cargo check --quiet</verify>
  <done>execute_search handles glob parameter correctly</done>
</task>
