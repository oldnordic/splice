<objective>
Create AST-aware symbol expansion infrastructure for retrieving full symbol bodies from tree-sitter parent chains.

Purpose: Enable users to retrieve full symbol definitions (not just name identifiers) by walking tree-sitter parent chains. This is the foundation for the `--expand` flag and progressive expansion features.

Output: A new `src/expand/` module with `expand_symbol()` function that takes a file path, byte offset, and language, then returns the expanded span covering the full symbol definition.
</objective>
