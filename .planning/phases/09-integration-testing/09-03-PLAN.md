# Overview

**Goal:** Verify cross-language compatibility for all 7 supported languages with their specific validation gates and compiler checks.

**Context from Phases 1-8:**
- Splice supports 7 languages: Rust, Python, C, C++, Java, JavaScript, TypeScript
- Each language has tree-sitter parsing
- Each language has validation gates (tree-sitter reparse + language-specific compiler/interpreter)
- Existing tests: `python_patch_tests.rs`, `cpp_patch_tests.rs`, `java_patch_tests.rs`, `typescript_patch_tests.rs`, `javascript_patch_tests.rs`

**Key Cross-Language Scenarios to Test:**
1. **Language-specific validation:** Each language's compiler/interpreter gate
2. **Multi-language workspace:** Mixed files in same workspace
3. **Language detection:** Auto-detection from file extension
4. **Symbol kind compatibility:** Functions, classes, methods across languages
5. **Import resolution:** Language-specific import patterns
