# Overview

**Goal:** Test end-to-end refactoring workflows covering the full patch/delete/plan/batch operations with real CLI commands.

**Context from Phases 1-8:**
- Phase 5 added line/column metadata to all operations
- Phase 6 ensured deterministic output ordering
- Phase 7 added checksum verification and pre/post hooks
- Existing `tests/cli_tests.rs` has 1575 LOC with basic CLI tests

**Key Workflows to Test:**
1. **Patch workflow:** Index → Resolve symbol → Apply patch → Verify → Rollback on failure
2. **Delete workflow:** Index → Find all references → Delete → Verify compilation
3. **Plan workflow:** Multi-step plan execution with failure stops
4. **Batch workflow:** Multi-file atomic operations
5. **Apply-files workflow:** Pattern-based replacement with AST confirmation
