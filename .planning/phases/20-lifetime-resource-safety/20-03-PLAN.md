  <action>
    Replace all instances of:
    ```rust
    .join("*.py").to_string_lossy().to_string()
    .join("*.rs").to_string_lossy().to_string()
    .join("**/*.rs").to_string_lossy().to_string()
    ```

    ```rust
    .join("*.py").to_str().expect("Invalid UTF-8 path").to_string()

    ```

    For lines 396, 435, 469, 510, 541, 590, 644, 703, 715, 784, 802, 830, 867, 920, 969, 1018, 1041, 1086, 1100, 1145, 1168, 1207, 1221, 1256, 1270, 1303, 1317, 1379, 1425, 1474, 1520, 1560 (glob_pattern assignments)


    ```rust
    .map(|m| m.file.file_name().and_then(|n| n.to_str()).unwrap_or_default().to_string())
    ```
    (Line 802 and similar)


    ```rust

    ```
    (Lines 1041, 1100, 1168, 1221, 1270, 1317)

    Rationale: Test code operates on temporary paths created by TempDir which are always valid UTF-8. Using expect() is acceptable here since it will never fail in practice. Using explicit defaults provides better error messages.
