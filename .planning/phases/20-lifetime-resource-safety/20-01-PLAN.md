    In test_manifest_save_and_load (line 417), replace:
    ```rust
    fs::create_dir_all(manifest_path.parent().unwrap()).expect("Failed to create dir");
    ```
    With:
    ```rust
    if let Some(parent) = manifest_path.parent() {
        fs::create_dir_all(parent).expect("Failed to create dir");
    } else {
        fs::create_dir_all(&manifest_path).expect("Failed to create manifest dir");
    }
    ```

    Rationale: Path::parent() returns None when the path is empty or just a filename. The unwrap() will panic in that case. Using if-let provides a safe fallback.
