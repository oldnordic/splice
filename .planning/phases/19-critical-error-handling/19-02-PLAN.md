    Current code (line 85-87):
    ```rust
    if text.len() > 2 {
        path = text[1..text.len() - 1].to_string();
    }
    ```

    And (line 95-97):
    ```rust
    if text.len() > 2 {
        path = text[1..text.len() - 1].to_string();
    }
    ```

    Replace both occurrences with character-safe slicing:

    ```rust
    if text.chars().count() > 2 {
        // Remove first and last character (quotes or angle brackets)
        let chars: Vec<char> = text.chars().collect();
        path = chars[1..chars.len() - 1].iter().collect();
    }
    ```

    This handles multi-byte UTF-8 characters correctly by working with chars instead of bytes.

    NOTE: tree_sitter's utf8_text() already returns valid UTF-8, so the source text is guaranteed valid. The issue is slicing by byte offset vs character offset.
  </action>
