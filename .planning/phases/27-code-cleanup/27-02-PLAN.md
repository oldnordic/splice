# Important Scope Limitation
From CONTEXT.md:
> **Out of scope:** Unused imports sweeping, dependency pruning (those are separate efforts)

This plan focuses ONLY on:
- Imports that trigger explicit compiler warnings
- Obvious unused imports (not borderline cases)
- Safe removals with clear verification

NOT doing:
- Comprehensive dependency analysis
- Removing unused crates from Cargo.toml
- Aggressive dead code elimination beyond imports
</context>

<tasks>

<task type="auto">
  <name>Task 1: Identify unused imports with compiler</name>
  <files>src/</files>
  <action>
    Run cargo check with warnings to identify unused imports:

    ```bash
    cargo check 2>&1 | grep -A 2 "unused"
    ```

    Capture all unused import warnings. Note the file and line number for each.

    Expected pattern:
    ```
    warning: unused import: `Foo`
    --> src/bar.rs:12:5
     |
    12 | use crate::foo::Foo;
     |     ^^^
    ```

    Create a list of files with unused imports to clean up. Only remove imports that have explicit warnings.
  </action>
  <verify>List of unused imports with file locations</verify>
  <done>All unused imports identified</done>
</task>

<task type="auto">
  <name>Task 2: Remove unused imports incrementally</name>
  <files>src/</files>
  <action>
    For each file with unused imports:

    1. Read the file
    2. Remove the specific unused import line(s)
    3. Run `cargo check` to verify compilation
    4. If compilation fails, restore the import and investigate

    Process files one at a time to isolate any issues.

    Example removal pattern:
    ```rust
    // BEFORE
    use crate::foo::Bar;
    use crate::foo::Baz;  // unused
    use crate::qux::Quux;

    // AFTER
    use crate::foo::Bar;
    use crate::qux::Quux;
    ```

    Keep a log of which imports were removed from which files.
  </action>
  <verify>Each file compiles after its imports are removed</verify>
  <done>All identified unused imports removed</done>
</task>

<task type="auto">
  <name>Task 3: Final verification with full test suite</name>
  <files>src/</files>
  <action>
    After all unused imports are removed, run the full test suite:

    ```bash
    cargo test
    ```

    This ensures that:
    1. The imports were truly unused
    2. No hidden dependencies via macros or traits
    3. All functionality still works

    Also run a final `cargo check` to verify no unused import warnings remain:

    ```bash
    cargo check 2>&1 | grep -i "unused" || echo "No unused warnings found"
    ```
  </action>
  <verify>All tests pass, no unused import warnings</verify>
  <done>Codebase is clean of unused imports</done>
</task>

</tasks>
