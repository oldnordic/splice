    Implement relationship query functions using CodeGraph backend:

    1. get_callers(graph, symbol_node_id) -> Vec<Relationship>
       - Query CodeGraph for incoming CALLS edges
       - For each caller, get node data (name, kind, file_path, byte_start, byte_end, line_start)
       - Convert to Relationship with rel_type="caller"
       - Return empty vec if >100 callers (threshold)

    2. get_callees(graph, symbol_node_id) -> Vec<Relationship>
       - Query CodeGraph for outgoing CALLS edges
       - For each callee, get node data
       - Convert to Relationship with rel_type="callee"
       - Return empty vec if >100 callees

    Note: CALLS edges are already defined in src/graph/schema.rs but not currently created. Use the EDGE_CALLS constant for consistency.

    Use graph.inner().query_edges() or similar backend API. Handle GraphError gracefully by returning empty vec with error message.
  </action>
