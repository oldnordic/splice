  <files>src/relationships/mod.rs</files>
  <action>
    Implement relationship query functions using CodeGraph backend:

    1. get_callers(graph, symbol_node_id, cache) -> Result<Vec<Relationship>, Relationships>
       - Check cache first: if hit, return cached results
       - Query CodeGraph for incoming CALLS edges
       - For each caller, get node data (name, kind, file_path, byte_start, byte_end, line_start)
       - Convert to Relationship with rel_type="caller"
       - Store in cache before returning
       - On error: return Relationships struct with error_code set to "REL_QUERY_FAILED" and error message

    2. get_callees(graph, symbol_node_id, cache) -> Result<Vec<Relationship>, Relationships>
       - Check cache first
       - Query CodeGraph for outgoing CALLS edges
       - For each callee, get node data
       - Convert to Relationship with rel_type="callee"
       - Store in cache before returning
       - On error: return Relationships with error_code="REL_QUERY_FAILED"

    3. Return empty vec if >100 callers/callees (threshold) - set error_code="REL_THRESHOLD_EXCEEDED"

    Note: CALLS edges are already defined in src/graph/schema.rs but not currently created. Use the EDGE_CALLS constant for consistency.

    Use graph.inner().query_edges() or similar backend API. Set error_code using Phase 11 format (ErrorCode.code style strings).
  </action>
  <verify>cargo check --lib passes</verify>
  <done>get_callers and get_callees functions traverse CodeGraph with caching and error codes</done>
</task>

    1. get_imports(graph, file_path, cache) -> Result<Vec<Relationship>, Relationships>
       - Check cache first
       - Query CodeGraph for all Symbol nodes with DEFINES edge from File node
       - Filter for symbols that are import statements (kind contains "import")

    2. get_exports(graph, file_path, cache) -> Result<Vec<Relationship>, Relationships>
       - Check cache first
       - Query CodeGraph for all Symbol nodes with DEFINES edge from File node
       - Filter for public symbols (pub fn, pub struct, exports)
       - Convert to Relationship with rel_type="export"
       - Store in cache before returning
       - On error: return Relationships with error_code="REL_QUERY_FAILED"
