2. For each failing test, update expected JSON to include new optional fields:
   - Add `context: { before: [], selected: [], after: [] }` if context is extracted
   - Add `semantic_kind: "function"` if semantic kind detected
   - Add `language: "rust"` if language detected
   - Add `checksum_before: "..."` and `file_checksum_before: "..."` if checksums calculated
   - Add `error_code: { code: "SPL-E001", severity: "error", ... }` for errors
   - Add `relationships: { callers: [], callees: [], imports: [], exports: [] }` if queried
   - Add `tool_hints: { requires_full_context: false, ... }` for applicable operations
   - Add `suggested_action: { action_type: "query", ... }` for applicable operations

3. Run tests again to verify:
   ```bash
   cargo test --all-targets
   ```

Example golden file update:
```rust
// OLD
let expected = json!({
    "file_path": "src/lib.rs",
    "byte_start": 0,
    "byte_end": 100
});

// NEW (with rich span fields)
let expected = json!({
    "file_path": "src/lib.rs",
    "byte_start": 0,
    "byte_end": 100,
    "context": {
        "before": ["line 1", "line 2"],
        "selected": ["selected line"],
        "after": ["line 4", "line 5"]
    },
    "semantic_kind": "function",
    "language": "rust",
    "checksum_before": "abc123...",
    "file_checksum_before": "def456..."
});
```

IMPORTANT: Only update golden files for non-breaking changes. If tests fail due to actual breaking changes (removed fields, type changes), fix the code instead.
