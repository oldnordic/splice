# Unix conventions to follow
- grep -A NUM: Print NUM lines of trailing context after matching lines
- grep -B NUM: Print NUM lines of leading context before matching lines
- grep -C NUM: Print NUM lines of output context (both before and after)
- git diff -C NUM is similar but for unified diff context
- When -C is used with -A or -B, the larger value takes precedence for that side
</context>
